Programs it never saw

The network was trained only while a universal Turing machine ran random little machines with up to five states, on tapes of up to six cells. Here it runs real programs, written for this page: the Collatz problem, a binary counter, a sort, addition, counting, the Fibonacci numbers. Every step of every run is checked against the program run directly.
