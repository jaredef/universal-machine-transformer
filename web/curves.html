The smallest network here was trained by gradient descent on nothing but the steps a universal Turing machine takes while running random little machines. Here it runs three programs it never saw, each a Turing machine that counts, in binary or in the Fibonacci number system, and computes for every number which way a line should turn. Every turn below was computed by the network, one forward pass at a time, live in your browser.
