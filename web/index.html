How this works

The tempting match for a language model pairs the Turing machine's tape with the context window. Here the match is different:

Turing machinethis transformer
the tapethe transcript: every token emitted, never overwritten
the head's viewthe context window: three tokens
the control statewritten into the transcript, read back through the window
the rule tablethe trained weights; one forward pass is one step

The window reads the old end of the transcript while each new token is appended at the far end. That turns the transcript into a queue, which is what makes the loop able to compute anything. A window that only sees the newest tokens, as in ordinary decoding, cannot.

The network never saw any of the named machines. It was trained only on the universal machine's steps while it ran 4,000 random machines on tapes of up to six cells. Every machine is written on the tape as data, so learning the universal machine's few local steps was enough to run them all. If your own machine needs a step the network never saw, the checks in panel 3 will say so.
